# Folder Popup — виджет всплывающей папки для KDE Plasma 6

[English](README.md) | [Русский](README.ru.md)

**Folder Popup** — виджет рабочего стола KDE Plasma 6, который отображает выбранную папку в виде компактного значка. По нажатию на значок открывается всплывающая панель с содержимым каталога. Виджет использует встроенную файловую модель KDE, поэтому типы файлов, значки, запуск элементов и контекстные действия обрабатываются средствами Plasma и KIO.

## Возможности

### Компактное представление

- Значок папки или выбранная системная иконка.
- Подпись под значком: пользовательский текст либо имя выбранной папки.
- Мини-превью содержимого папки в виде мозаики до четырёх значков.
- Подсветка при наведении указателя с использованием цвета активной темы Kirigami.
- Открытие и закрытие панели коротким нажатием левой кнопки мыши.

### Всплывающая панель

- Сетка файлов и папок с системными значками KDE.
- Названия элементов с переносом и ограничением длины.
- Переход внутрь папок и возврат на предыдущий уровень.
- Открытие файлов, приложений и интернет-ссылок средствами KDE/KIO.
- Кнопка открытия текущей папки в файловом менеджере.
- Автоматический размер всплывающей панели: ширина подстраивается под количество ячеек, используется до четырёх столбцов, а для небольших папок их количество сокращается. Для окна задаются одинаковые динамические минимальный и максимальный размеры, поэтому оно следует рассчитанному размеру сетки даже при наличии ранее сохранённого Plasma размера popup.
- Если содержимое не помещается по высоте экрана, сетка становится вертикально прокручиваемой.
- Штатное контекстное меню KDE для отдельного файла или папки.
- Переименование через контекстное меню и диалог Folder Popup.
- Сообщения о загрузке, пустой или недоступной папке.
- Содержимое папки обновляется файловой моделью KDE при изменениях в каталоге.

### Файлы `.desktop`

Для ярлыков приложений и интернет-ссылок используются системные значки из файлов `.desktop`. Подпись берётся из ключа `Name` группы `[Desktop Entry]`. Если для текущей локали задано локализованное поле, например `Name[ru_RU]`, KConfig выбирает соответствующее значение. Для чтения имени используется `kreadconfig6`; если утилита недоступна или имя не удалось получить, в качестве запасного варианта отображается имя файла.

Пример ярлыка приложения:

```ini
[Desktop Entry]
Type=Application
Name=Firefox
Name[ru_RU]=Firefox
Exec=firefox %u
Icon=firefox
Terminal=false
```

Пример интернет-ссылки:

```ini
[Desktop Entry]
Type=Link
Name=Мой сайт
URL=https://example.org/
Icon=internet-web-browser
```

Folder Popup отображает значок и имя ярлыка. Запуск элемента выполняют системные компоненты KDE; виджет не использует значение `Exec` для чтения подписи.

## Настройки

В настройках виджета можно задать:

- папку для отображения;
- ширину и высоту компактного значка;
- размер значков элементов;
- максимальное количество отображаемых элементов;
- сортировку по имени, типу, дате изменения или размеру;
- обратный порядок сортировки;
- отображение скрытых файлов;
- отображение подписей к элементам;
- имя системной иконки компактного виджета;
- собственную подпись под значком;
- включение или отключение мини-превью содержимого папки.

Компактное представление по умолчанию занимает 1×1 ячейку; его размер можно изменить в настройках. Всплывающая панель подстраивается под содержимое автоматически: использует до четырёх столбцов, сокращает ширину для папок с небольшим количеством элементов и рассчитывает высоту по числу строк. Для больших папок высота ограничивается доступной областью экрана, а сетку можно прокручивать. По умолчанию отображается не более 64 элементов.

## Локализация

**Английский — исходный язык и язык по умолчанию.** Если язык рабочего стола Plasma — русский (`ru`, включая региональные варианты, например `ru_RU`), встроенный русский перевод выбирается автоматически. Настраивать язык в самом виджете не требуется.

- `translate/ru.po` — редактируемый русский перевод.
- `translate/template.pot` — шаблон исходных английских строк.
- `contents/locale/ru/LC_MESSAGES/plasma_applet_io.github.wadehusky.folderpopup.mo` — скомпилированный русский каталог, включённый в пакет.

После изменения `ru.po` пересоберите каталог с помощью GNU gettext (`msgfmt`):

```bash
sh translate/build.sh
```

Затем пересоберите пакет виджета, чтобы обновлённый каталог попал в архив.

## Требования

- KDE Plasma 6.
- Qt 6 и компоненты Qt Quick, Qt Quick Controls, Qt Quick Dialogs и Qt Quick Layouts.
- Kirigami и модули Plasma, включая Plasma5Support.
- Внутренняя файловая модель Plasma `org.kde.private.desktopcontainment.folder`.
- `kpackagetool6` для установки и удаления виджета.
- `kreadconfig6` для получения локализованного значения `Name` из `.desktop`-файлов. Если утилита недоступна, виджет использует имя файла.
- `zip` для сборки пакета из исходного репозитория.
- GNU gettext (`msgfmt`) для пересборки русского каталога переводов.

Виджет рассчитан на Plasma 6. Поскольку файловая модель `org.kde.private.desktopcontainment.folder` является внутренним API Plasma, совместимость с будущими выпусками Plasma может потребовать адаптации.

## Установка из исходного репозитория

Распакуйте архив или клонируйте репозиторий и перейдите в его корневой каталог. Выполните:

```bash
./build.sh
./clean-install.sh
```

Скрипт установки удаляет ранее установленную копию Folder Popup, устанавливает собранный пакет и проверяет наличие основных QML-файлов. Для его работы требуется `kpackagetool6`.

После установки перезапустите Plasma Shell:

```bash
kquitapp6 plasmashell
kstart plasmashell
```

В качестве альтернативы можно завершить сеанс KDE и войти снова.

## Установка готового пакета

Если у вас уже есть файл `.plasmoid`, установите его командой:

```bash
kpackagetool6 --type Plasma/Applet --install /путь/к/io.github.wadehusky.folderpopup-1.0.0.plasmoid
```

Затем перезапустите Plasma Shell или перезайдите в сеанс. Добавьте Folder Popup на рабочий стол через режим редактирования рабочего стола Plasma и выберите нужную папку.

## Первый запуск и настройка

1. Добавьте Folder Popup на рабочий стол Plasma.
2. Откройте настройки виджета.
3. Выберите папку с помощью кнопки обзора или укажите URL, например `file:///home/user/Documents`.
4. Настройте размер компактного значка, размер значков элементов, подписи и сортировку. Размер всплывающей панели рассчитывается автоматически.
5. При необходимости задайте собственную подпись и имя системной иконки.
6. Включите или отключите мини-превью содержимого папки.
7. Нажмите на компактный значок, чтобы открыть содержимое папки.

Короткое нажатие левой кнопкой мыши открывает или закрывает панель.

## Диагностика

Для просмотра сообщений Plasma и QML выполните:

```bash
journalctl --user -f -o cat | grep --line-buffered -Ei 'Folder Popup|folderpopup|plasmashell|QML|FolderModel'
```

Если `.desktop`-ярлык отображается под именем файла, проверьте наличие `kreadconfig6`:

```bash
command -v kreadconfig6
```

Убедитесь, что файл ярлыка содержит группу `[Desktop Entry]` и ключ `Name=`. Для русской подписи можно добавить `Name[ru_RU]=...`.

Если папка не открывается, проверьте её URL/путь и права доступа. Сообщения об ошибках файловой модели можно найти в выводе `journalctl`.

## Удаление

```bash
kpackagetool6 --type Plasma/Applet --remove io.github.wadehusky.folderpopup
```

Если после удаления файлы пакета остались, удалите локальный каталог виджета:

```bash
rm -rf ~/.local/share/plasma/plasmoids/io.github.wadehusky.folderpopup
```

После удаления перезапустите Plasma Shell или завершите и снова откройте сеанс KDE.
